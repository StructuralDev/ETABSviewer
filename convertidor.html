Convertidor de modelos ETABS

Todo se procesa en este navegador: los archivos originales no se suben a ningún lado.

  1. Escribe el nombre del cliente o proyecto.
  2. Elige una vez la carpeta de bibliotecas de tu ETABS y agrega cada modelo (.e2k).
  3. Genera el paquete: se descarga un archivo .enc.json. Envíalo a quien lo publica y la contraseña por otro canal (no en el mismo mensaje).

1. Cliente o proyecto

2. Bibliotecas de perfiles de ETABS

El .e2k solo trae el nombre de los perfiles de catálogo (p. ej. HSS8X8X1/4, archivo AISC14); su área está en las bibliotecas de tu instalación de ETABS. Elige una vez la carpeta Property Libraries (normalmente C:\Program Files\Computers and Structures\ETABS 23\Property Libraries): solo se leen los archivos que cada modelo necesita y quedan guardados en este navegador. No se suben a ningún lado ni se incluyen en el repositorio. Si no tienes ETABS a la mano, sirve la tabla de secciones exportada (paso 3).

Cargar bibliotecas sueltas (.xml)

    3. Modelos

    Aún no hay modelos. Agrega el primero abajo.

    Agregar un modelo

    El .e2k (File → Export → ETABS .e2k File) y, solo si el modelo tiene perfiles que no están en las bibliotecas (secciones propias o de otra norma) o no tienes las bibliotecas a la mano, la tabla de propiedades de secciones de frame: Display → Show Tables → Model Definition → Section Properties → Frame Section Properties y luego File → Export → Excel (sirve el .xlsx tal cual). El modelo nuevo se agrega al final.

    4. Contraseña

    Se genera una al azar. El repositorio es público: la contraseña es lo único que protege los modelos, así que debe ser larga y distinta por cliente. Compártela por un canal distinto al del archivo y del enlace.

    Opciones avanzadas (quien publica)

    Abrir un paquete existente

    Para renombrar, reordenar o quitar modelos, o cambiar etiquetas, colores y notas de un paquete ya publicado. Elige su archivo models/<id>.enc.json y escribe su contraseña. Para crear uno nuevo, sáltate este paso.

    Identificador y nota general

    Es el nombre del archivo y lo que va después de ?c= en el enlace.
