Convertidor de modelos ETABS

Uso interno. Todo se procesa en este navegador: los archivos originales no se suben a ningún lado.

1. Paquete (cliente o proyecto)

2. Bibliotecas de perfiles (opcional)

El .e2k solo trae el nombre de los perfiles de catálogo (p. ej. HSS8X8X1/4, archivo AISC14); su área está en la biblioteca de ETABS. Las bibliotecas AISC 14, 15 y 16 (y sus versiones métricas) ya vienen incluidas y se usan solas según el FILE del .e2k. Carga aquí una biblioteca propia solo si tu modelo usa otra (.xml de la carpeta Property Libraries de ETABS); se guarda en este navegador y tiene prioridad sobre la incluida.

    3. Modelos

    Por cada modelo: el .e2k (File → Export → ETABS .e2k File) y, solo si el modelo tiene perfiles que no están en las bibliotecas (secciones propias o de otra norma), la tabla de propiedades de secciones de frame: Display → Show Tables → Model Definition → Section Properties → Frame Section Properties y luego File → Export → Excel (sirve el .xlsx tal cual).

    4. Acceso

    Usa una contraseña distinta por cliente. El repositorio es público: la contraseña es lo único que protege los modelos, así que debe ser larga. Compártela por un canal distinto al del enlace.
