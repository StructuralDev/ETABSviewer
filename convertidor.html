2. Bibliotecas de perfiles de ETABS

El .e2k solo trae el nombre de los perfiles de catálogo (p. ej. HSS8X8X1/4, archivo AISC14); su área está en las bibliotecas de tu instalación de ETABS. Elige una vez la carpeta Property Libraries (normalmente C:\Program Files\Computers and Structures\ETABS 23\Property Libraries): solo se leen los archivos que cada modelo necesita y quedan guardados en este navegador. No se suben a ningún lado ni se incluyen en el repositorio. Si no tienes ETABS a la mano, sirve la tabla de secciones exportada (paso 3).

    3. Modelos

    Agregar un modelo

    El .e2k (File → Export → ETABS .e2k File) y, solo si el modelo tiene perfiles que no están en las bibliotecas (secciones propias o de otra norma) o no tienes las bibliotecas a la mano, la tabla de propiedades de secciones de frame: Display → Show Tables → Model Definition → Section Properties → Frame Section Properties y luego File → Export → Excel (sirve el .xlsx tal cual). El modelo nuevo se agrega al final.

    4. Acceso

    Usa una contraseña distinta por cliente. El repositorio es público: la contraseña es lo único que protege los modelos, así que debe ser larga. Compártela por un canal distinto al del enlace.
